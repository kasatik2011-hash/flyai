# FlyAI

Современный русскоязычный авиационный помощник на Next.js. FlyAI отвечает в пределах авиационной тематики, обращается к настоящей языковой модели OpenAI через серверный API и может искать актуальные сведения в интернете. Ссылки на найденные источники отображаются рядом с ответами.

## Подключение ИИ

1. Создайте API-ключ в кабинете OpenAI.
2. Добавьте его в серверные переменные окружения приложения:

   ```env
   OPENAI_API_KEY=ваш_секретный_ключ
   OPENAI_MODEL=gpt-4.1-mini
   ```

3. Перезапустите приложение. Переменная `OPENAI_MODEL` необязательна; если её нет, используется `gpt-4.1-mini`.

**Не добавляйте ключ в `NEXT_PUBLIC_*` и не вставляйте его в клиентский код.** Ключ используется только в обработчике `src/app/api/chat/route.ts`. Для веб-поиска и запросов модели также требуется доступ к OpenAI API.

Если ключ не настроен, интерфейс честно покажет статус подключения, а чат вернёт инструкцию по настройке вместо имитации ответов.

## Разработка

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). В диалоге поддерживаются быстрые авиационные вопросы, история текущего разговора, новый диалог и источники для ответов с веб-поиском.
